# Changelog

## 1.1.0
- Now has separate jars for different Minecraft version ranges
  - Use the jar with the latest version less than or equal to your Minecraft version
  - eg. For running 1.16.5 you would download the 1.14.4 jar
- Support for Minecraft 1.14.4 - 26.3 and every version in between

## 1.0.3
- Fix the mod not working on the newest Minecraft versions.
